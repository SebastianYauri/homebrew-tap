# Homebrew tap for Clawdy

[Clawdy](https://github.com/SebastianYauri/clawdy) is a tiny pixel buddy that shows your Claude usage
and acts out what Claude Code is doing.

```sh
brew install --cask sebastianyauri/tap/clawdy
```

For Apple silicon Macs. Clawdy updates itself; the cask follows each new release automatically.
